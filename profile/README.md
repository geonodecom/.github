# Geonode

### Web data for AI agents. Search the web and turn pages into usable content.

Give your AI agents and applications the web data they need with Geonode, delivered through MCPs, SDKs, APIs and integrations. Collect website content with web scraping, retrieve SERP search results and turn live information into useful workflows. For direct web access, use residential, ISP and datacenter proxies. Try web scraping for free.

## Connect your assistant

Use the hosted [Geonode MCP Server](https://github.com/geonodecom/mcp) with a compatible client:

```text
https://mcp.geonode.com/mcp
```

Limited anonymous page extraction is available. Additional tools and account usage require a Geonode API key. See [authentication and limits](https://docs.geonode.com/docs/scraper-api/guides/mcp/01_before-you-start). Ready-made agent skills are in [skills](https://github.com/geonodecom/skills).

## What will you build?
